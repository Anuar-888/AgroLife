# Ресурсы

- `farm-landscape.jpg`: фотография поля с Unsplash, источник файла: https://images.unsplash.com/photo-1500382017468-9049fed747ef . Иллюстрация, не фотография конкретного хозяйства в Казахстане.
- `berries.jpg`, `vegetables.jpg`, `fruits.jpg`: иллюстрации из предоставленного репозитория https://github.com/Anuar-888/AgroLife, первоначально `app/src/main/res/drawable-nodpi/cat_*.png`; оптимизированы для веба. Оригинальное авторство и права не установлены в репозитории, перед публичным коммерческим использованием их следует подтвердить либо заменить ресурсами с известной лицензией.
- `Manrope-Variable.ttf`: Manrope, Google Fonts (https://github.com/google/fonts/tree/main/ofl/manrope), SIL Open Font License 1.1. Текст лицензии: `Manrope-OFL.txt`.
- `GolosText-Variable.ttf`: Golos Text, Google Fonts (https://github.com/google/fonts/tree/main/ofl/golostext), SIL Open Font License 1.1. Основной шрифт сайта и кабинета с версии 0.2. Текст лицензии: `GolosText-OFL.txt`.
- `favicon.svg` и линейные иконки интерфейса: SVG, написанные для этого прототипа.

Все ресурсы лежат в этой папке. Сайт не загружает шрифты, фотографии, аналитику или скрипты с внешних сервисов.
