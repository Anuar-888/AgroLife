# AgroLife Backend

Simple API for the AgroLife Android application.

## Setup

1. Install Node.js
2. Navigate to this folder: `cd backend`
3. Install dependencies: `npm install`
4. Start the server: `npm start`

## Endpoints

- `GET /api/crops`: List of available crops.
- `GET /api/fields`: List of user-defined fields.
- `POST /api/fields`: Create a new field.
- `GET /api/health`: Check server status.
